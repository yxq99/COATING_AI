# 完整涂层 EIS 与机器学习数据填写说明

## 从哪里开始

日常只填写 [ML_data.xlsx](ML_data.xlsx)，保存后运行 `prepare-eis`。程序从同一套数据训练、预测和推荐，不再使用 `data_kind`，没有 real/demo 模式开关。

本次已经生成两个模型及 `round_01/` 三个推荐配方的待测模板，可直接填写现有这一轮。模型路径见 `current_runs.json`。不要重复覆盖 round_01；若重新推荐，请使用 round_02 等新目录。

当前六条 EIS 轨迹来自原 EP/SACA/Si_SACA/BTA 数据。两个配方输入是为了调试接口人为指定的数字，不是这些原材料实测的 MXene 配方；来源、已知重复、名义时间与原始记录保留在“来源映射”。目前只能验证软件流程，不能据此发表 MXene 性能、最优配方或可靠性结论。

## 两个连续配方输入

- `hybrid_wt_pct`：复合填料质量/全部涂层干固体质量×100，填写数值 0.2 表示 0.2 wt.%，不是 20%。
- `ldh_mxene_ratio`：干基 LDH 质量/MXene 质量，数值 1.5 表示 1.5 g/g，不是百分数。PDA、BTA-ZIF-8 及其他工艺先固定。

当前演练范围分别为 0.1–1.5 wt.% 和 0.1–2.0 g/g，不构成推荐的真实制备范围。正式实验前修改“参数”。如果实际只能确定投料比，应记录为名义投料比，后续不要与实测产物质量比混用。

## 主工作簿各表怎么填

| 表 | 已有内容 | 后续填写方式 |
| --- | --- | --- |
| 配方 | P01–P06 演练输入；N001–N003 空白占位 | 每个不同配方一行，填两个连续量；同配方重复不新增配方号 |
| EIS低频 | 六条轨迹各六时刻，共36条；R2/R3与新配方结果空白 | 录入0.01Hz模值（Ω）、实际面积（cm²）、制备/试片编号及时间 |
| EIS全谱 | 从所选36个PAR提取的2549个原始频点 | 备查；保留实部、虚部的原始正负号 |
| 实验条件 | 9个样品的基材、树脂、膜厚、介质、温度等空位 | 按真实记录填，不用0代表未知 |
| 参数 | 两输入范围、后期目标日、最低logZ、风险惩罚等 | 修改这里后重新整理；目前目标为28天、演练阈值10 |
| 来源映射 | 原材料、名义时间、原PAR路径、复制件、哈希、幅值/日期 | 追溯用；未来真实记录换成对应自己的源文件 |
| 新谱模板 | 一条100kHz–0.01Hz的71点频率网格，测量值全空 | 若选择粘贴全谱，填写样品/制备/试片/天数及实虚部；频率按实际可修改 |

黄色是主要录入区域。R1只是现有轨迹的占位编号，不能证明独立制备；R2/R3留空，等待真正重新配制后的测量，不复制R1。

六个时刻为1、3、7、14、28、50天。主流程使用1/3/7天作早期信息，28天作后期标签。50天已保留，目标日可改14/28/50；这不等于多年寿命预测。

同一配制的多片技术重复使用同一个 `preparation_id`、不同 `specimen_id`；重新称量、混合、制片才用新的 `preparation_id`。程序先在一次配制内聚合，再统计配制间均值与SD。

## 如何录入 EIS

最简单：直接填“EIS低频”的 `z_001_ohm` 和 `area_cm2`。若仪器输出已是 Ω·cm²，不要再乘实际面积，可先换算回 Ω；程序当前统一按 Ω×cm²计算。不能混用两种单位。

也可只在“新谱模板”填完整实部/虚部，并在“EIS低频”建立同一试片/同一天的行及实际面积，保留模值为空。程序自动提取确切的0.01Hz点，不把0.0126Hz冒充0.01Hz，不外推。

更新已有记录时，若同时保留全谱和低频值，两者必须一致；有冲突会报错，不会自动选择更高值。全谱是辅助输入，不用于伪造新的独立训练样本。

`raw_eis/` 中保存36个所选原始PAR复制件，无需联网即可追溯本次使用的数据。优先选择包含0.01Hz的记录，再按幅值、文件名固定排序，不按性能好坏选取。它不是对原数据真实性/正式版本的确认，详细问题仍见项目的电化学数据可行性报告。

## 一步整理数据

在 PyCharm 的 AI 环境、项目根目录执行：

```bash
python -m coating_ai prepare-eis
```

程序只重建以下派生文件，不改工作簿和原始PAR：

| 文件 | 用途 |
| --- | --- |
| design_training.csv | 已有后期标签的配方训练表：两个配方输入→后期logZ |
| early_training.csv | 配方＋1/3/7天logZ→后期logZ训练表 |
| design_prediction_inputs.csv | 输入已填、后期结果未测的新配方，供制备前预测 |
| early_prediction_inputs.csv | 输入及1/3/7天已填、后期未测的新配方，供早期更新预测 |
| repeat_statistics.csv | 各配方各时刻的均值、SD、独立配制编号数量 |
| project.yaml | 配方设计的有效设置；命令行默认使用此文件 |
| early_model.yaml | 早期预测有效设置；仅用于train/validate/predict，不允许搜索观测EIS特征 |
| preparation_summary.json | 完整记录数、待预测数、目标与未实现功能说明 |
| current_runs.json | 本次已检查的两个模型目录及待填写轮次；重新训练后以终端的新路径为准 |

只用完整标签训练；未测结果不会从预测值回填，空白也不会变成0。当前只有单条名义轨迹，SD为空而非0。没有新实验时，两张待预测表可能只有表头，这是正常状态。

## 配方模型训练与下一批推荐

```bash
python -m coating_ai train --data data/design_training.csv
python -m coating_ai recommend --run outputs/刚生成的训练目录 --out-data data/round_02
```

训练目录要替换成终端实际打印的路径。为快速检查可在train后加 `--skip-cv`，正式评价不跳过验证。`validation_group` 使已知同源重复的P03/P05、P04/P06分别同折；这仍不能修复原数据归属问题。

本次已生成的 `data/round_01/`（重新推荐示例会生成 round_02）包含：

- `candidates_to_measure.csv`：真正推荐的两个连续配方输入，目标列空白。
- `measurements.csv`：每个推荐配方R1/R2/R3、六时刻的空白结果；实际测得后填模值和面积。
- `spectra.csv`：单条全谱的通用空白格式，不是模拟结果；按需要复制完整频率块并填写编号。

同一轮已存在时不覆盖，下一轮换 `data/round_02`。不要将输出目录里的 `predictions_not_measurements.csv` 当成实测回填。

## 早期模型训练、预测和实验回填

```bash
python -m coating_ai train --settings data/early_model.yaml --data data/early_training.csv
```

新实验做到7天后，填写round_01的配方及早期测量，再整理：

```bash
python -m coating_ai prepare-eis --new-data data/round_01
python -m coating_ai predict --settings data/early_model.yaml --run outputs/早期模型训练目录 --data data/early_prediction_inputs.csv
```

还没测的14/28/50天继续留空。若没有可预测记录，程序会说明尚缺新配方或早期测量，不会制造数据。

做到28天后填入同一份测量表，再运行prepare-eis；完整新配方自动进入训练表，然后重新train。预测冻结快照留在outputs，不因回填而改写旧预测。

多轮的数据可先录入主工作簿统一管理；`--new-data` 每次只补充一个指定目录，不会自动搜索所有历史轮次。已经录入主工作簿的同一轮不要再重复传入，否则重复编号校验会报错。

## 可靠性接口目前的边界

已有数据用于测试均值预测、推荐、保存/加载及回填。当前没有独立重复，不会给出实证可靠性或95%达标概率。

`required_success_probability` 只是未来概率模型的预留要求，当前不参与评分；参数中 `risk_aversion` 惩罚潜在函数不确定性，不是制备波动。当前mean/latent_std预测与重复统计不能冒充完整可靠概率模型。

先把数据流跑通，之后用真实独立重复开发概率校准/约束。当前新实验结果明确留空，因此闭环会在“等待测量”处停下，这是正确行为，而不是用模型答案伪造闭环成功。

## 日后替换真实数据

保留表头与编号规则；替换配方、EIS和实验条件；清除旧全谱及不再使用的演练记录；给真实独立配方设置适当的验证组；修改范围与目标；再运行prepare-eis并重新训练。没有real/demo开关，也无需复制两个项目。

请备份主工作簿和新实验CSV。派生CSV/YAML可重建，主工作簿、源文件和实测回填不可随意覆盖。
